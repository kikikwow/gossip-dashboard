DeepSeek 刚刚以 Apache-2.0 许可证开源了其高性能大规模推理框架 DeepInfer。支持功能：优化的算子、模型与采样器运行时；并行：Attention DP / 均衡 CP、MoE EP + EPLB；DSpark 与按置信度调度的验证；SWA 有界重放；异步调度（零开销批调度器）；批次不变推理；确定性采样；结构化输出。

DeepSeek just open sourced its high-performance, large-scale inference framework DeepInfer in Apache-2.0 license. https://github.com/deepseek-ai/DeepInfer Supported features: - Optimized kernels, model and sampler runtime - Parallelism: Attention DP / balanced CP, MoE EP + EPLB - DSpark and confidence-scheduled verification - SWA bounded replay - Asynchronous scheduling (zero-overhead batch scheduler) - Batch-invariant inference - Deterministic sampling - Structured output
